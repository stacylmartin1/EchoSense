EchoSense App restructure: 
Rename the app to EchoSense instead of Google AI Edge Gallery
The app should have no dependancy on an internet connection. Model download is available but not required so app should not hang retrieving model list.
The app has 6 tasks.
	- Navigation Assistance
    - Collision avoidance
	- Currency Mode
	- image/document reader (pdf/text sh)
	- image/document translator
	- AI Chat
All tasks use features of the current echosense task except AI Chat (preview screen, tts, collision avoidance, LLM inference/reset, settings). All tasks are implemented such that they can use android accessibility features (screen reader, etc.). 
- Add settings in existing settings screen to control preveiw screen enable/disable, text overlay enable/disable, concise/verbose LLM reponses for all tasks. 
- Navigation Assistance: Existing echosense task without collision avoidance. Preview screen and text overlay controlled from settings. Must persist text overlay until next inference starts. Include scroll bar if text runs off the end of display
- Collision Avoidance: Existing collision avoidance function from exisiting echosense task. Enhance with available device native features (LIDAR, other?). 
- Currency mode
take a photo or upload an image of a bank note. Use LLM to analyze country and denomination and read aloud via tts. Display text on screen per settings control. Persist text until next analysis.
- Document reader. Analyze text from photo and read aloud via tts. or upload txt/pdf document from device storage and read aloud. Control paging of uploaded document. Document reader does not use LLM except in the case of images.
- Document translator. Same as Document reader except any text to english.
- AI Chat. Use existing AI Chat from AI edge gallery. (support speech input via microphone as well as keyboard input, response uses TTS along with text)
Remove original AI Edge Gallery tasks Ask Image, Audio scribe, Prompt Lab, tiny garden, mobile actions.
Remove unused files and functions
